# Elorce Software Solutions website preview

Open index.html in a browser. The site is a static, multi-page preview with no build step or package dependencies. The pages share site.css and site.js.

The forms are intentionally local-only previews: they validate required fields and show a notice, but do not send or save application/contact data. See SITE-AUDIT.md for the live-site review, preserved content and publishing follow-up.
